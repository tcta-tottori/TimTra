# 署名鍵

`debug.keystore` は開発用の署名鍵（パスワード `android`、別名 `androiddebugkey`）。

- GitHub Actions のランナーは毎回別の debug 鍵を生成するため、鍵を固定しないと
  「パッケージが既存のパッケージと競合する」となり上書きインストールできない。
- スマホ版と Wear 版はこの同じ鍵で署名する（Wearable Data Layer の通信条件）。
- 個人用アプリで Play 配信はしないため、この鍵をそのまま使う。公開配布する場合は別の鍵に差し替え、
  この鍵はリポジトリから外すこと。

鍵を差し替えたときは、端末側の TimTra をいったんアンインストールしてから入れ直す。
